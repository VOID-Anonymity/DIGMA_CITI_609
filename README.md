# 🌑 Digma CITI 609 (MT6739) — Stock Recovery & Archive

**Digma CITI 609 Vault** — это священный архив оригинальных компонентов и дампов для смартфона Digma CITI 609 на чипсете MediaTek MT6739. Настоящий артефакт спасения для тех, чья система пала в цифровое небытие, а устройство превратилось в молчаливый кирпич.

> "Из Бездны спасенный, к жизни возвращенный."

---

## 🗡 Содержимое святилища

В этом репозитории сокрыты базовые ресурсы, вырванные из недр чистой системы LineageOS 17.1 и стока:

* **📜 Stock Recovery Image (`recovery.img`):** Нетронутый дамп заводского раздела восстановления для возврата к истокам.
* **📦 Vendor & System Archives:** Сжатые в Бездне образом компрессии дампы системных разделов (ищи в **[Releases](https://github.com/VOID-Anonymity/DIGMA_CITI_609/releases)**).

Для полной трансформации устройства используй связанные ритуальные репозитории:
